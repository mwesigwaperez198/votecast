# VoteCast - DA-VELA HOUSE OF ART Live Voting & Scoreboard

VoteCast is the live audience voting and scoreboard system for DA-VELA HOUSE OF ART events. It helps organizers run a smooth fashion-show voting experience from registration to final winner announcement, while keeping every vote visible on a live display for the audience.

## What the system does
- Lets attendees register quickly with their name, email, and phone number from a QR-driven voter page.
- Opens a live ballot for audience voting during the event session.
- Gives admins and judges a secure control dashboard to manage contestants, session states, and winner decisions.
- Shows a live scoreboard on a projector or secondary screen for real-time rankings.
- Records votes and registration activity in the admin logs for event monitoring.

## Project focus
VoteCast is designed for DA-VELA HOUSE OF ART runway events, with a clean, modern presentation and a simple voting flow that feels natural for live audience participation.
