# VoteCast - DA_VELA Fashions

VoteCast is the live audience voting and scoreboard system for DA_VELA Fashions by Novara Technologies Limited. It allows guests to register and vote from their phones, gives admins control of the event flow from a CMS, and displays live results on a projector or secondary screen.

## Experience

- Voter registration and live model voting
- Admin dashboard for contestants, session timing, and event control
- Live leaderboard for the runway and winner announcement
- QR-based audience access
- Logged registrations and event activity
